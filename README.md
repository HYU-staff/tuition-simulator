# 등록금·정원 재정 시뮬레이터

한양대학교 기획처 예산팀 · 등록금 인상률과 정원·편제 개편을 함께 검토하는 **단일 HTML 의사결정 도구**입니다.
설치나 서버 없이 `dist/tuition-simulator.html`을 브라우저(Chrome·Edge)로 열면 바로 동작하며, 인터넷 연결이 없어도 됩니다.

> ⚠️ **내부 업무용** — 이 저장소는 **Private**으로 운영하세요. 집계값(계열·학과별 인원/금액)이 포함되어 있습니다.
> 학번 등 개인정보가 있는 RAW 엑셀은 `.gitignore`로 제외되어 있으며 **절대 커밋하지 않습니다.**

---

## 주요 기능

| 탭 | 내용 |
|---|---|
| **① 등록금 인상률** | 법정 상한(직전 3개년 CPI 평균 × 1.2) 자동 산출 · 인상률 구간별 수입 대시보드 · 시나리오 A/B/C 자동 추천 + **D(수기 입력)** · 민감도 · 국가장학금 Ⅱ유형 영향 · 최종 가이드 |
| **② 정원·편제 개편** | 학부 계열별 코호트(학년 진급) 모델 · 감축/계열 이동/충원율 · 가격·자연·구조 효과 분해 · 인상률×이동률 최적 조합 그리드 · 시나리오 A/B/C |
| **공통** | 당해연도 징수통계 RAW 업로드(매년 갱신) · 데이터 검증표 · 두 탭 **연동 스위치** · 검토결과 **엑셀(12개 시트) 내보내기** |

기준값(내장 데이터): 2026학년도 연간 등록금 수입 **434,363,657,000원**(연구등록 4,807,136,000원 포함).

## 사용 방법

1. `dist/tuition-simulator.html`을 더블클릭해 브라우저로 엽니다.
2. (매년) ① 탭 **0. 기준 데이터** 영역에서 당해연도 `학과별징수총액통계표` RAW 엑셀을 업로드합니다.
   - 필수 열: 연도, 학기, 정원내외구분, 대학(원)구분, 계열명, rc캠퍼스, 수업료, 합계, 외국인구분, 연구등록구분 등
   - 선택 열(학년·학번·학과전공명)이 있으면 ② 탭 코호트 파라미터도 자동 재산출됩니다.
   - 업로드 데이터는 브라우저(localStorage)에만 저장되며 외부로 전송되지 않습니다.
3. 좌측 입력값(CPI, 인상률 범위, 장학금 등)을 조정하고 대시보드·시나리오를 확인합니다.
4. 우측 상단 **검토 결과 엑셀로 내려받기** 버튼으로 엑셀 보고서를 저장합니다.

자세한 화면 설명은 [`docs/user-manual.pdf`](docs/user-manual.pdf)를 참고하세요.

## 폴더 구조

```
tuition-simulator/
├─ dist/tuition-simulator.html   # 배포용 완성본(단일 파일, 이것만 공유하면 됨)
├─ src/                          # 수정은 여기서
│  ├─ head.html                  # <title> + CSS(디자인 토큰·반응형)
│  ├─ body.html                  # 화면 마크업(① ② 탭, 입력 패널, 표 영역)
│  ├─ seg.js                     # ① 탭 기준 세그먼트 81개(캠퍼스×과정×계열×내외국인)
│  ├─ sp.js                      # ② 탭 코호트 파라미터(계열별 학년 인원·진급률·단가, 학과 136개)
│  ├─ app.js                     # ① 탭 엔진·렌더링·RAW 업로드/검증
│  ├─ st.js                      # ② 탭 코호트 엔진·최적조합·탭 연동
│  ├─ export.js                  # 엑셀 검토결과 내보내기
│  └─ vendor/xlsx.full.min.js    # SheetJS 0.18.5 (Apache-2.0)
├─ tools/
│  ├─ params.py                  # 통합 RAW → 코호트 파라미터(P.json) 산출
│  ├─ ref.py                     # 코호트 엔진 Python 참조 구현(교차검증)
│  └─ P.sample.json              # 2026 기준 파라미터 예시
├─ docs/user-manual.pdf          # 사용 매뉴얼
└─ build.py                      # src → dist 빌드
```

## 수정 후 빌드

```bash
python build.py        # dist/tuition-simulator.html 재생성 (Python 3.8+, 추가 패키지 불필요)
```

스크립트 결합 순서는 `seg → sp → app → st → export`이며 순서를 바꾸면 동작하지 않습니다.

## 검증

```bash
cd tools
python ref.py P.sample.json
# 기본가정(인상 2.5%) 2026~2030 수입(억원) — 시뮬레이터 화면 값과 일치해야 함
# [4343.6, 4495.7, 4627.5, 4731.9, 4809.6]
# 개편 없음: [4343.6, 4534.8, 4707.5, 4856.9, 4984.3]
```

파라미터 재산출(새 RAW 반영, `pandas`·`openpyxl` 필요):

```bash
python tools/params.py 통합본.xlsx P.json   # '통합RAW' 시트를 읽음
```

## 모델 요약

- **① 탭**: 세그먼트별 단가(전액 등록자 수업료 최빈값)·실효율 k = 금액/(단가×인원) → `수입 = Σ 단가·(1+r)·인원·충원·(k + 납부율 조정)`
- **② 탭**: 학부 계열별 코호트(의예+의학 6년, 약학 6년, 그 외 4년+초과학기) · 진급률은 2025→2026 학기평균 인원 비(0.7~1.3 범위 외는 가중평균 대체) · 대학원은 연 감소율, 연구등록은 고정
- **법정 상한**: 직전 3개년 CPI 평균 × 1.2 (2027 추정 2.8%) · 권고안(B) = min(상한−버퍼, 최근 CPI)를 인상률 간격(기본 0.5%p) 단위로 내림

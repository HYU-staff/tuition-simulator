# 등록금·정원 재정 시뮬레이터

등록금 인상률과 정원·편제 개편을 함께 검토하는 **단일 HTML 의사결정 도구**입니다.
설치나 서버 없이 `dist/tuition-simulator.html`을 브라우저(Chrome·Edge)로 열고, 당해연도 등록금 징수통계 RAW 엑셀을 올리면 바로 계산됩니다. 인터넷 연결이 없어도 동작합니다.

> 🔒 **이 저장소에는 내장 데이터가 없습니다.**
> 징수액·인원 등 실적 데이터와 RAW 엑셀은 저장소에 포함하지 않으며 `.gitignore`로 커밋을 막아 두었습니다.
> 데이터는 실행할 때 사용자가 직접 업로드하고, 업로드한 자료는 그 PC의 브라우저 안에서만 처리·저장됩니다(외부 전송 없음).

---

## 주요 기능

| 탭 | 내용 |
|---|---|
| **① 등록금 인상률** | 법정 상한(직전 3개년 CPI 평균 × 1.2) 자동 산출 · 인상률 구간별 수입 대시보드 · 시나리오 A/B/C 자동 추천 + **D(직접 입력)** · 민감도 · 국가장학금 Ⅱ유형 영향 · 최종 가이드 |
| **② 정원·편제 개편** | 학부 계열별 코호트(학년 진급) 모델 · 감축/계열 이동/충원율 · 가격·자연·구조 효과 분해 · 인상률×이동률 최적 조합 그리드 · 시나리오 A/B/C |
| **공통** | 당해연도 징수통계 RAW 업로드(매년 갱신) · 데이터 검증표 · 두 탭 **연동 스위치** · 검토 결과 **엑셀(12개 시트) 내보내기** |

## 사용 방법

1. `dist/tuition-simulator.html`을 더블클릭해 브라우저로 엽니다. 처음에는 "기준 데이터가 없습니다" 안내가 표시됩니다.
2. ① 탭 **0. 기준 데이터**에서 「엑셀·CSV 파일 선택」으로 `학과별징수총액통계표` RAW를 올립니다.
   - 당해연도 1·2학기 파일(또는 여러 해가 섞인 통합 RAW). 한 학기만 있으면 연간 환산(×2) 선택 가능
   - **전년도 RAW를 함께 올리면** ② 탭 학년별 진급률을 실적으로 산출합니다(없으면 1.0 유지 가정).
   - 필수 열: 연도, 학기, 대학(원)구분, 계열명, rc캠퍼스, 외국인구분, 연구등록구분, 정원내외구분, 수업료, 합계 등
   - ② 탭에는 학년·학번·학과전공명 열이 추가로 필요합니다.
3. 좌측 입력값(CPI, 인상률 범위, 장학금 등)을 조정하고 대시보드·시나리오를 확인합니다.
4. 우측 상단 **검토 결과 엑셀로 내려받기**로 보고서를 저장합니다.
5. 다음에 열면 마지막으로 올린 자료를 브라우저가 기억합니다. 「올린 자료 지우기」로 초기화합니다.

## 폴더 구조

```
tuition-simulator/
├─ dist/tuition-simulator.html   # 배포용 완성본(내장 데이터 없음, 이 파일만 공유하면 됨)
├─ src/                          # 수정은 여기서
│  ├─ head.html                  # <title> + CSS(디자인 토큰·반응형)
│  ├─ body.html                  # 화면 마크업(① ② 탭, 입력 패널, 표 영역)
│  ├─ data/empty.js              # 빈 데이터 정의(내장 데이터 자리 · 형식 설명)
│  ├─ app.js                     # ① 탭 엔진·렌더링·RAW 업로드/검증
│  ├─ st.js                      # ② 탭 코호트 엔진·최적조합·탭 연동
│  ├─ export.js                  # 엑셀 검토 결과 내보내기
│  └─ vendor/xlsx.full.min.js    # SheetJS 0.18.5 (Apache-2.0)
├─ tools/
│  ├─ params.py                  # 통합 RAW → 코호트 파라미터(P.json) 산출
│  └─ ref.py                     # 코호트 엔진 Python 참조 구현(교차검증)
└─ build.py                      # src → dist 빌드
```

## 빌드

```bash
python build.py                                   # → dist/tuition-simulator.html (데이터 없음, 커밋용)
python build.py --data local-data/embedded.js     # → build-local/… (내장 데이터 포함, 내부 배포용)
```

- Python 3.8+ · 추가 패키지 불필요. 스크립트 결합 순서는 `data → app → st → export`입니다.
- `local-data/`, `build-local/`은 `.gitignore` 대상이라 커밋되지 않습니다.
  내장 데이터 파일은 `src/data/empty.js`와 같은 변수(`SEGS`, `RESEARCH`, `EMB_SEM`, `EMB_META`, `SP_EMB`)를 채운 형태입니다.

## 검증 도구

```bash
python tools/params.py 통합본.xlsx P.json   # '통합RAW' 시트 → 코호트 파라미터 (pandas·openpyxl 필요)
python tools/ref.py P.json                  # 기본가정 5개년 수입(억원) — 화면 ② 탭 값과 일치해야 함
```

## 모델 요약

- **① 탭**: 세그먼트(캠퍼스×과정×계열×내외국인)별 단가(전액 등록자 수업료 최빈값)·실효율 k = 금액/(단가×인원) → `수입 = Σ 단가·(1+r)·인원·충원·(k + 납부율 조정)`
- **② 탭**: 학부 계열별 코호트(의예+의학 6년, 약학 6년, 그 외 4년+초과학기) · 진급률은 전년→당해 학기평균 인원 비(0.7~1.3 범위 밖은 가중평균 대체) · 대학원은 연 감소율, 연구등록은 고정
- **법정 상한**: 직전 3개년 CPI 평균 × 1.2 · 권고안(B) = min(상한−버퍼, 최근 CPI)를 인상률 간격(기본 0.5%p) 단위로 내림
